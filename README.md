Task Tracker CLI
Una herramienta de línea de comandos robusta para gestionar tareas, construida en Python puro (sin dependencias externas) siguiendo una arquitectura limpia y principios de desarrollo profesional.

🚀 Características
CRUD Completo: Agregar, actualizar, eliminar y listar tareas.

Gestión de Estados: Cambia el estado a todo, in-progress o done.

Persistencia: Almacenamiento automático en un archivo JSON.

Interfaz Colorida: Mensajes de éxito y error visualmente claros en la terminal.

Arquitectura Profesional: Separación de responsabilidades (Storage, Manager, CLI Handlers).

Testeo Integral: Pruebas unitarias, de integración y de almacenamiento.
